# Ummahti Public

Public website and operational publishing surface for Ummahti Quran.

The repository is a framework-free static site deployed with Cloudflare Pages. The repository root is the Pages output directory; no build command is required.

Public routes: `/`, `/privacy`, `/terms`, and `/support`.

The existing `updates/`, `ops/`, `emergency/`, and `youtube/` machine-readable paths remain at their original URLs.
