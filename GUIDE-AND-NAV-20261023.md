# Broader Guide answers and app-derived preview navigation

The owner liked the corrected release but rejected Happy ending with no
content. They chose **Quran passages and prepared guidance**, rather than
conversational AI, for broader questions. They also requested the real app's
bottom navigation, made more polished in every render.

Both Guide forms now keep search available for any wording. Existing reviewed
topics remain intact. A shared answer layer accepts natural framing, common
synonyms/typos, Arabic words and numeric references. Happy opens 10:58, 13:28
and 16:97 with a short source-based introduction. Negated Happy and unhappy
do not become positive joy or unrelated marriage guidance. Broader searches
use an on-demand index of the unchanged Arabic and Saheeh International
corpus, across all 6,236 ayahs. Results include neighbouring context and open
directly in the website. Unclear/unrelated wording receives clearly labelled
starting passages and suggested prepared topics, not a fabricated answer.

The index is 2,170,457 bytes, requested only for broad corpus searches and
reused thereafter. Prepared topics, Happy and direct references do not need
it. Source scripts carry original text and translation. No query transport,
query storage, AI provider, external dependency or security-policy change.
Index/corpus loading errors remain retryable; edits, newer requests and hidden
tabs cannot be overwritten by an older result. Quran ranges are validated;
explicit ranges longer than ten ayahs disclose that the first ten are shown.

All three interactive phones share the app's Home / Read / Guide / Saved /
Settings bar, actual simplified crescent and selection-ring geometry. Source:
`HomeScreen.kt:rememberNavItems`, `UmmahtiNavRail.kt` and
`UmmahtiMotionGeometry.kt` in the Android reference tree. Labels use the app's
English/Arabic/Urdu/Indonesian resources. The browser treatment adds a quiet
glass gradient, rim, bloom and finite selected-ring travel. Hifz belongs to
Read, Guide to Guide, and the Unlock home background to Home. The navigation
is decorative app chrome; existing named demo controls remain authoritative.
Original screenshot assets and Android source are unchanged.

Validation: eight actual-controller Node suites, generator/static checks,
index digests and all 6,236 translation coordinates. Expanded controller
coverage includes Happy in all four locales, direct references, lazy-index
failure/retry and stale completion after a different question. Static checks
require all three app bars, five correct labels/order, one selected slot,
helper ordering, local forms and preserved connect-src none. Browser evidence
and exact deployment are recorded in the shared-brain handoff. Physical-device
testing and native review of draft copy remain pending.

No standards change required. This extends the existing static website;
it does not change the Android app or claim to answer every personal ruling.
